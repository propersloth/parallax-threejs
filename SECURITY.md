# Security Policy

## Supported versions

This project is pre-1.0 with a single active release line. Only the most
recently published `latest` version on npm (and the corresponding
`parallax-threejs`/`parallax-threejs-stable` marketplace entries) receives
security fixes — there's no parallel maintenance of older versions.

## Reporting a vulnerability

Please report security issues privately, not via a public GitHub issue:

- Preferred: use GitHub's [private vulnerability
  reporting](https://github.com/propersloth/parallax-threejs/security/advisories/new)
  (Security tab → "Report a vulnerability"). This opens a private advisory
  visible only to the maintainer until a fix is ready.
- Alternative: email sean.c.odonnell@gmail.com.

Include what you'd normally include in a bug report — affected version,
reproduction steps, and impact — plus anything specific to why it's a
security concern rather than a regular bug.

This is a single-maintainer project without a formal SLA; expect an initial
response, not necessarily an immediate fix.
